## 🎯 Objective

Predict whether **Team 1 wins the match** using historical IPL data by building a machine learning-based prediction system.

---

## 📊 Key Analysis

- Team performance trends across seasons  
- Venue impact on match outcomes  
- Toss influence on winning probability  
- Top batsmen based on runs and strike rate  
- Top bowlers based on wickets and economy rate  

---

## ⚙️ Feature Engineering

- **Team Strength (Win %):** Overall performance of each team  
- **Strength Difference:** Relative strength between competing teams  
- **Toss Advantage:** Whether Team 1 won the toss  
- **Venue Encoding:** Capturing ground-specific effects  

---

## 🤖 Model

- **Algorithm:** Logistic Regression  
- **Problem Type:** Binary Classification  
- **Performance:** ~60–70% accuracy on unseen data
